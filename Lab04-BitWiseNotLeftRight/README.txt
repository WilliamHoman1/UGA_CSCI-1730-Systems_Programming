Compilation Instructions:
------------------------
gcc -Wall lab04.c -o lab04.out

Run Instructions:
-----------------------
This program supports three usage forms:

1. Bitwise NOT:
./lab04.out -not <bitstring>

2. Left Shift:
./lab04.out <bitstring> -leftshift <amount>

3. Right Shift:
./lab04.out <bitstring> -rightshift <amount>


This program will print the result of the operation both as a bit string and a
base-10 unsigned integer.
