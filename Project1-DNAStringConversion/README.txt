Compile and run instructions
----------------------------
1. Place all files (compress.c, compress.h, decompress.c, decompress.h, and proj1.c) in the same directory
as the Makefile.
2. Compile with "make compile"
3. Run program to compress a DNA string:
   ./proj1.out -c <DNA_STRING>

4. Run the program to decompress a DNA string:
   ./proj1.out -d <LENGTH> <BYTE_1> <BYTE_2> ..

5. To remove compiled files:
   "make clean"
